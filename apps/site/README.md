# apps/site

This folder is intentionally empty. Scaffold your SvelteKit app here by running,
from the repo root:

    npx sv create apps/site

Choose the options you want during setup (TypeScript, routing style, etc).
Once it's created, import the tokens and components like this in your root
layout or main component:

    import "@hydra/tokens/dist/tokens.css";
    import { Button } from "@hydra/svelte";
